【正常工作流程】
匯入影片 → ComfyUI 去背 → 素材檢查 → 接點修整
→ 素材與順序 → 一鍵修復全部接點 → 播放驗收 → 預覽與輸出。

單段：一支動畫，選「順序循環（最後接回開頭）」。
多段：加入完成去背的動畫，以 ↑／↓ 排順序；循環會處理最後一段接回第一段。
只需 A→B→C 播完停止，選「播完結束（不接回開頭）」。
不依檔名猜順序。同組來源必須同畫布，最多 16 段，一鍵修復每段至少 6 幀。

【修復與驗收】
需要統一明暗時，先到「進階微調 → 進階：整組明暗與手動校準」，選基準段，
按「統一整組明暗」。明暗本來一致就略過；這不是片內逐幀去閃爍。
回到「修復與驗收」，按「一鍵修復全部接點」或「重新修復全部接點」。
工具先量測／穩定整段微小比例漂移，再以本地 RIFE 重建頭尾過渡。
完成直接套用並儲存，無須先分析或按安全套用；可復原／重做。
取代舊頭尾幾何對位，保留明暗設定。原解析度、FPS、保留範圍幀數不變。
原始 PNG 保留；比較、慢播、整路線預覽與輸出共用同一份修復 PNG。

選接點按「0.1× 慢播修復結果（已套用）」，再到下一步用正常速度看整條路線。
注意接點跳動、整段比例起伏、表情重影與明暗閃爍。循環也要看最後→第一段。
確認滿意才標記可用；端點相同不代表過渡自然。修改來源、順序、範圍或微調後須重修。
「比例待檢查」表示保留原比例或未能跨段共同校準；不代表接縫修復一定失敗。
貼邊保留既有覆蓋，不保證生成原素材未曾出現的身體部位。
正常流程不必開「進階：僅分析、不重建影格」；那裡是舊分析與未套用試算。
詳細實作、驗證及限制：docs/v3.12-stability.zh-TW.md。
單表情已獲維護者實測認可；多表情已做合成驗證，真實素材驗收仍在進行。

【保存與版本】
接點草稿自動保存至磁碟；固定區的「儲存」可立即保存，失敗會提示。
復原／重做是本次開啟的操作歷史，重新整理後不保留歷史，不替代版本備份。
保存方案只保存設定，輸出才產生 PNG／WebM。輸出完成會載入當次版本。
輸出時繼續修改，不會把新修改加入正在輸出的版本；請留意草稿／成品不同提示。
草稿整路線可先預覽。正式成品預覽讀取輸出 PNG，並保留固定來源／方案身分。

重跑去背會替換該幀原始去背 PNG，並讓先前影片、接點計算與確認狀態失效。
舊影片仍可查看，但會標「來源已更新」；來源未核對的舊記錄不宣稱最新。
原影片不受接點修整影響。接點編輯保存參數與不可變修復 PNG 快取，正式輸出另存版本。

【舊單段方案相容入口】
新工作優先用接點修整。需要保留舊方案的保護圈、內部參考幀或特殊漸變時，
從「進階／相容」打開舊單段編輯器；升級不會把它偷偷轉成不等價的新方案。
舊單段仍從任務的原始去背 PNG 開始；播放器選了舊版本不會更換它的來源。
瀏覽器草稿仍屬舊模式，長期保存要按「儲存方案」。參考圖不隨草稿保存。
自選參考圖片僅供明暗比對，不會寫入成品；重新開頁需再選。

【畫面與控制】
符合視窗：保持比例顯示完整畫布。100%／200%：檢查細節，超出視窗時捲動。
直／橫式會按畫布及可用高度安排；需要更多空間可按「專注畫布」。
「顯示設定」提供舒適 16／大字 18 及六款配色。底色、字級、縮放不寫入成品。
保存與復原固定可見。接點慢播提供 0.1×；先確認載入完成再判斷畫面。
短播末尾跳回短播起點不是原接縫；完整路線在預覽與輸出檢查。

【這個包包含什麼】
Windows 原始碼分享套件，使用本機瀏覽器操作，不是免安裝 EXE。
包含工作臺、固定節點的 Qwen 2.1 API 工作流、安裝腳本及說明。
不含 Python、ComfyUI、模型、FFmpeg、使用者圖片、影片、任務、銜接專案與日誌。
分享乾淨 ZIP 即可；不要直接壓縮自己正在使用的整個工具目錄。

【第一次安裝】
1. 完整解壓縮至可以寫入的資料夾，例如 D:\AnimationWorkbench。
   不要在 ZIP 內執行，也不要放進 Program Files 或唯讀資料夾。
2. 安裝 Windows x64 Python 3.12，保留 Python Launcher（py）。
   官方：https://www.python.org/downloads/windows/
3. 雙擊 setup.cmd（分享包也提供「第一次安裝.cmd」）。需要網路，會安裝
   NumPy 2.3.5、Pillow 10.4.0、SciPy 1.17.0、opencv-python-headless 4.11.0.86
   到工具專用 .venv，不修改全域套件。
4. 自行安裝 FFmpeg 與 FFprobe，須有 libvpx-vp9 編碼器及解碼器。
   官方入口：https://ffmpeg.org/download.html
   可加入 PATH，或將完整套件的 bin 放到 tools/ffmpeg/bin。
   shared 版的相關 DLL 也必須在 bin 內，不能只複製 EXE。
5. 準備能執行隨附工作流的 ComfyUI。模型與自訂節點清單見「依賴與限制.txt」。
6. 先啟動 ComfyUI，再雙擊「啟動工具.cmd」（或 start.cmd）。
   網址：http://127.0.0.1:8767
   按「＋ 匯入影片」，展開「模型設定與環境檢查」，再按「檢查環境」。
   缺少節點或模型時，先在 ComfyUI 安裝／確認名稱，再重新檢查。

一鍵修復另需 NVIDIA CUDA PyTorch 與 RIFE：先完成 docs/model-setup.zh-TW.md；
setup.cmd 不會代裝接縫模型。已配置完成且 Python 位置未變的電腦可沿用。

【匯入與任務隊列】
選取多支影片，或拖進匯入面板的虛線框；可分次追加，單次最多 100 支。
支援 MP4、MOV、MKV、WebM、AVI、M4V、OGV、GIF；實際解碼依 FFmpeg。
輸出無音軌。FPS 留白時各支沿用來源 FPS，再以固定幀率時間軸拆成 PNG。
起始幀從 1 算，處理幀數留白做到片尾；改 FPS 也會改變幀編號。
本次匯入共用幀範圍、模型設定；單支匯入失敗會顯示原因，其他有效影片仍可加入。

「加入隊列並開始」會依序去背；「僅加入隊列」不主動啟動已暫停的隊列。
若隊列原本正在執行，新加入的任務會接在後面。預設整段去背，也可選每支先試跑。
試跑預設連續 48 幀，可改成一個循環長度；完成後需檢查、確認，才處理剩餘影格。
隊列可暫停／繼續、調整待處理順序、移出或重新排隊。單支失敗不阻擋下一支。
「檢查素材」開啟該素材；「確認效果，排入全片去背」排入剩餘影格，
若隊列已暫停，仍須按「開始／繼續隊列」。
暫停保留已完成影格；已送出的 ComfyUI 請求可能仍在背景完成。
重新啟動後隊列保留，但要手動繼續；「移出隊列」不刪除影片或已產生的 PNG。
批次完成後，到「接點修整」按「更新來源」，即可加入新完成的動畫。

【需要時再用：進階微調】
進階區預設收起，但已有的對位、變形或單段明暗等設定仍保留。
看到「已套用」／「使用中」提示，可按提示查看；收起區塊、換步驟不會停用效果。
相容單段與接點編輯器的進階區提供自動局部對位、位置、變形、單段明暗、
保留範圍、所有銜接方向及人工檢查記錄。固定循環通常先檢查列出的相鄰接點即可。

自動局部對位適合相似姿勢的小幅差異，會估算對應線條後平滑變形，不是生成式補畫。
單段固定修尾幀到參考 A 幀；多段修 A 尾時參考 B 頭，修 B 頭時參考 A 尾。
每段的頭／尾各存自己的強度。啟用對位會替代該端手動變形；停用會恢復原手動數值。
來源端點改動需重算。對位參考是計算當時的畫面，切換比較來源不等於重新對位。
100% 候選量測不能代表較低強度或共用接點後的最終效果，請以最新畫布與實際成品為準。

手動變形可調位移、縮放、旋轉，尾段修正逐漸加入；多段頭尾則向中段恢復。
「只修框內」／「保護框內」可用矩形或橢圓，支援移動、拖邊角、座標與羽化。
「框內／框外分別調整」讓兩區有獨立位移、縮放、旋轉，羽化平滑銜接邊界。
「貼邊固定（中間修整）」保留指定側邊原位置；可分別選左右側與調整過渡範圍。
進入框選後拖曳是編輯選區，完成後才恢復拖曳比對。操作線與手柄不寫入輸出。
選區只限制幾何變形；明暗與對比仍作用整段畫面。舊保護圈仍支援。
少量調整後放大檢查：貼邊過渡可能拉伸，框內外差距過大可能拉扯，不能補畫缺失內容。
畫布固定；過渡折疊或越界可能被拒絕。這不是自由網格液化工具。

多段的「所有銜接方向」用列 A 尾、欄 B 頭表示各方向，包含自循環。
A → B、B → A、A → A 是不同接點；片段設定或來源改動後，相關人工確認會失效。
分數只是輪廓、外觀與動作線索，不代替播放判斷；不同表情也可能有合理差異。

【怎麼看比對畫面】
先看畫布附近的來源與幀號，再選比對方式。
拖曳比對：左右分開查看兩張圖。半透明疊圖：混合顯示，不代表兩張已完全重合。
輪廓差異：紅 A、青 B，只檢查 Alpha 外框；內部線條、明暗請搭配「差異 ×4」。
多段修改設定後，若還顯示上次的圖，畫布會標「舊預覽／正在更新／更新失敗」。
等更新成功再判斷；錯誤時先依訊息處理，不能將舊圖當成目前設定。
來源標示、預覽縮放、底色及分析分數都不會寫進成品。

【明暗與幾何的關係】
明暗 LUT 本身不改 Alpha，但其後的變形／光流過渡會重新取樣影像與 Alpha。
因此整條修整管線不能只憑 LUT 宣稱透明邊緣不變。明暗改變後要重核對相依接點。
本版快速預覽使用與正式輸出相同的幾何順序，再縮小顯示；仍須原尺寸看細節。

【輸出時間與成品預覽】
「結果與版本」集中查看單段任務、原去背與修整成品、資料夾及驗證資訊。
輸出狀態顯示當前階段、幀數、已用與預估剩餘時間；原去背完成不代表修整輸出也完成。
估計按已完成速度計算，只代表當前階段，後續階段另標；資料不足時顯示正在估算。
不要在去背、輸出中關閉服務、安裝更新或搬移任務資料夾。
越界或來源變動會停止輸出；已生成候選檔仍保留，請修正後另存新版本。

接點成品預載實際 PNG，但為減少用量，預覽長邊最多 720 px，
再依總幀數縮小至約 384 MiB 解碼像素預算；這不是整個瀏覽器 RAM 的硬上限。
需縮到長邊低於 256 px 才能載入時，會請你減少幀數或分組；
原圖本就小於 256 px 不強制放大。畫面會分開標示預覽與輸出尺寸，原成品不改寫。
需核對原尺寸細節時，按「開啟資料夾」看該版本 PNG。
共用端點完全相同仍可能短暫停頓；大幅姿勢差、遮擋或新增／消失細節仍可能扭曲。
本工具不保證任意中途切換無縫，也未內建 RIFE。

【檔案位置與分享】
jobs/素材名稱/transparent_png：原始去背 PNG。
jobs/素材名稱/output：原去背 WebM、設定與驗證 JSON。
jobs/素材名稱/loop_edits/修整[_序號]：單段另存版本、PNG、WebM、方案及驗證。
jobs/素材名稱/_cache：拆幀與模型暫存，處理期間不要刪除。
uploads：上傳影片副本；貼路徑則直接讀取原檔。
batch_queue.json：本機隊列；重開後手動繼續。
transition_projects/<專案>/project.json：表情組設定，需連同 jobs 來源一起備份。
transition_projects/<專案>/repairs：不可變修復影格快取，需連同專案保存。
transition_projects/<專案>/anchors：共用接點快照，編輯方案備份須一併保留。
transition_projects/<專案>/versions/v001：一次整組輸出、manifest、快照、狀態及各段資料夾。
各段內含 transparent_png、animation.webm、verification.json、ffmpeg.log。
JSON 是設定或驗證記錄，不是影片，也不是遊戲動畫切換邏輯，平常無須手動修改。
再次分享請使用乾淨 ZIP，不包含 jobs、uploads、transition_projects、隊列、日誌或截圖。

【透明影片與引擎】
WebM 使用 VP9 Alpha、無音軌；完成會回讀透明度，與 PNG 最大差異需不超過 2/255。
PNG 是主要素材，WebM 色彩取樣仍可能造成小幅邊緣差異。
部分播放器忽略 Alpha；若顯示底色或白邊，請與工作臺預覽及 PNG 對照。
Godot 4 內建 VideoStreamPlayer 不直接提供 WebM 播放，需相容擴充；
也可用 PNG 序列建立 AnimatedSprite2D。透明度驗證合格不代表所有播放器都支援。

草稿整路線預覽長邊最多 360 px，另有限制解碼與傳輸記憶體；超過時會提示分組，
不會偷偷丟幀或更改輸出解析度。預覽縮放不代表輸出尺寸。

【故障處理與升級】
找不到 py：重新安裝 Python 3.12 並啟用 Launcher。
找不到 NumPy／Pillow／SciPy／OpenCV：重跑 setup.cmd，檢查網路與安裝錯誤。
找不到 ffmpeg／ffprobe：檢查 PATH 或 tools/ffmpeg/bin。
找不到模型／節點：對照依賴清單；本工具不是任意工作流匯入器，節點 ID 已固定。
同名修整版本刪掉重做：按「更新來源」重新辨識內容，受影響的舊確認需重新檢查。
若整個任務已刪除，新匯入是新任務；請移除失效來源再加入，不會只憑同名替換。
「無法連線到工作台」：重新啟動工具後再重新整理。
