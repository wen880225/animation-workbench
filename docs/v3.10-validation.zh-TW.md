# v3.10 三批整合：驗收與升級說明

驗收日期：2026-10-07。此版是本機更新，尚未發布 GitHub Release 或建立新版分享 ZIP。

## 這次完成的三批

1. **可靠性**：修正慢播準備、快速換接點、停止與新請求間的競爭；保存依序提交。來源重新生成、草稿改動與固定成品分別追蹤，舊成品不再被當作目前設定的結果。失敗會顯示原因。
2. **整併**：正常入口為「素材檢查／接點修整」。單段、多段共用「素材與順序 → 分析與修正 → 預覽與輸出」，儲存／復原／重做固定可見。循環與播完停止明確分開；只有實際路線接點進入正常檢查清單。舊單段特殊方案留在進階相容入口。
3. **自動化**：先分析，再一次套用符合保守門檻的明暗與接點修正，例外留待人工確認。套用可整批復原；草稿可直接播放完整路線，輸出成功後自動載入該次固定版本。過期的自動設定有明示修復計畫，不會在分析時偷偷改寫。

## 實際 GUI 驗收

全部使用另外建立的中性機器人影格與測試專案，在隔離服務完成。沒有使用使用者的素材測試。

| 案例 | 實際結果 |
| --- | --- |
| A：單段循環 | 從目前素材建立單段接點專案，只有尾→首一個接點。可 0.1× 慢播；輸出並載入 v001，共 36 張、180×320 PNG。大動作差異保留待檢查。 |
| B：三段開放序列 | 批次加入 A／B／C，只列 A→B、B→C；整路線播放停在 C 第 36／36 幀，不繞回 A。輸出並載入 v001，共 108 張 PNG。 |
| C：六段循環 | 一次加入六段，一次復原清空、重做還原。只列六個必要接點；分析得到一段可修正明暗與十項待檢查。套用、復原、重做及輸出通過；載入 v001，共 216 張 PNG。 |
| 小差異正例 | 320×180、兩段各 24 幀的小差異素材，分析得到一段明暗及兩個接點可修正，無待檢查。套用、草稿整路線播放及 48 張 PNG 輸出通過；兩個端點均一致。 |

正例的端點一致不代表所有生成動畫都能自動修好。合成負例故意包含較大動作，工具正確留下待檢查，而不是宣稱全部合格。

## 升級與恢復

本次只更新程式、教學與測試檔。來源影格、任務、接點專案、成品與使用者設定不會搬移或覆寫。原始審計文件保持原樣。

舊程式備份位於工具根目錄 `backups/` 下本次 v3.10 更新資料夾，含檔案雜湊清單與恢復說明。備份不包含使用者素材；可編輯專案需依新手教學另外備份。

執行中的正式服務沒有被停止或重啟。準備使用新版時：

1. 保存工作，等處理完成並暫停隊列。
2. 執行 `重新啟動工作台.cmd`。
3. 確認頁面右下顯示 v3.10，並從「接點修整」繼續。若瀏覽器仍顯示舊內容，重新整理。

缺少路線／分析能力的舊後端會被新版介面拒絕，避免把「播完停止」誤當成循環保存。

## 已知界線

- 本輪未執行 ComfyUI／Qwen 模型推論、不同 GPU 或全新 Windows 安裝驗收；原有去背環境要求不變。
- 本版沒有 Seam AI Inspector，不會把演算法指標當作語義判斷或人工驗收。
- 明暗使用每段固定曲線，不是逐幀去閃爍；手勢、表情、遮擋與生成缺陷可能需要人工修正。
- 自動接點修正採保守門檻，檢查實際過渡區，不能保證任意大變形素材都能平順銜接。
- 較佳端點搜尋是有限範圍建議，不自動裁掉動作。
- 完整草稿預覽長邊最多 360 px，含記憶體及傳輸預算保護；輸出仍保持原尺寸。超大組請縮小範圍或拆組。
- 明暗 LUT 保留 Alpha；幾何與光流過渡可能重新取樣 Alpha。重跑去背仍會更新原始去背 PNG，請自行備份重要來源。
- 復原／重做限目前開啟專案的編輯歷史，不是長期備份。
- 輸出無音軌；PNG 是主要驗收依據。遊戲引擎的播放／透明影片支援仍需另行整合。
